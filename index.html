Screen mirror

Launches scrcpy in its own window. In-app embedding of the video stream is a later upgrade — see the README.

Camera preview

Streams the phone's camera to a preview window via scrcpy's camera video source. This is the video half of a "use phone as webcam" feature — making it selectable inside other apps (Zoom, OBS, browsers) needs a signed virtual-camera driver per OS, which isn't built yet. See the README for what that would take.

Audio & media controls

Forwards device audio (music, media playback) to your PC speakers via scrcpy, and sends standard media-key commands to whatever app holds the active playback session.

Pulls shared storage folders and, optionally, installed APKs to a folder on this PC. This isn't a full system/app-data backup — modern Android doesn't allow that without root — just what's reachable from userspace adb.
